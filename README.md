#DESCRIPTION:
This project is a basic interactive quiz website created to practice JavaScript logic and dynamic content handling inside a browser. The aim of the project is to understand how question-based systems work and how user answers can be processed instantly without using any database or backend service. The application is designed as a simple learning exercise rather than a full examination platform.

The website displays multiple choice questions one at a time. The user selects an option and moves to the next question. At the end of the quiz, the final score is calculated and displayed automatically. The questions are shuffled using JavaScript array methods so the order changes each time the quiz starts. This makes every attempt slightly different and prevents remembering answer positions.

The quiz runs completely inside the browser. All checking of answers happens using JavaScript conditions and event handling. No login system or user account is required. The quiz can be restarted multiple times and works independently without saving permanent records.

The interface is kept simple and readable so users can focus on answering questions. Clear buttons and spacing help avoid confusion. Basic responsive styling allows the layout to adjust on mobile and desktop screens. The design avoids complex animations to keep performance fast and lightweight.

This project helped in understanding DOM manipulation, event listeners, conditions, loops, and array operations in JavaScript. It demonstrates how interactive educational content can be built using only core front-end technologies.

Overall, the project represents a beginner-level implementation of an online quiz showing how questions, answers, and scoring logic work together inside a web page.

#TECHOLOGY USED:

CSS: styling and layout
JavaScript: quiz logic, randomization, and score tracking
